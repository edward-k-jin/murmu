# Project Brief

## User Goal
이미 신뢰가 형성된 두 사람이 폐쇄된 1:1 공간에서 텍스트로 속마음을 안전하게 나누는 iOS/Android 앱을 출시한다.

## Target User
연인, 배우자, 오래된 친구처럼 사적인 감정을 나눌 신뢰가 이미 있는 1:1 관계. 연령이나 직업보다 관계의 친밀도와 반복적인 교류 여부가 중요하다.

## Problem
단체 메신저는 일상 대화가 빠르게 흘러가 속마음을 꺼내기 어렵고, 공개 SNS는 관계 범위가 넓어 민감한 감정을 공유하기 어렵다. 한 사람에게도 지금 바로 말하기 힘든 감정을 안전하게 남기고 준비된 시점에 대화로 이어갈 공간이 필요하다.

## Product Principles
- 혼잣말이 메인이고 대화는 공개된 혼잣말의 스레드 안에서만 이뤄진다.
- 혼잣말 공개 대상은 항상 1:1 공간의 상대 한 명이다.
- 작성자가 공개 시점을 통제한다.
- 1:1 공간 사이의 피드, 알림, 멤버십, 권한, 기록을 완전히 분리한다.
- 감정 표현은 무료로 유지한다.

## MVP Scope
- 3단계 Welcome 온보딩, Apple/Google 로그인, 닉네임 온보딩
- 1:1 공간 생성 및 초대 참여
- 한 사용자의 여러 1:1 공간 생성/참여와 공간 전환
- 공간 정원 2명 고정, 세 번째 참여 서버 거부
- 공간 생성자 권한: 초대 발급, 상대 제거
- 혼잣말 작성: 기분, 텍스트, 즉시 또는 예약 공개
- 공개 전 피드에는 기분과 잠김 상태만 노출
- 공개된 혼잣말의 스레드 대화
- 일일 기분 체크인과 상대 기분 현황
- 혼잣말 공개와 새 스레드 메시지 푸시
- 만든 사람의 상대 존재 시 탈퇴 차단
- 상대 나가기와 만든 사람의 상대 제거
- 나가기·제거 즉시 해당 공간 전체 접근 차단
- 나가기·제거 전 공개된 혼잣말과 스레드의 작성자 표시 보존
- 나가기·제거 시 작성자의 미공개 예약 혼잣말 자동 취소

## Non-Goals
- 3명 이상 그룹, 그룹 구독, 인원 확장
- 이미지, 동영상, 음성 콘텐츠
- 공개 피드, 팔로우, 검색 기반 소셜 네트워크
- 독립 상시 채팅
- 특정 멤버 대상 혼잣말
- P0 구독 결제, AI 리포트, 이모티콘 상점
- P0 일본어 현지화

## Success Criteria
- 신규 사용자가 1:1 공간을 만들거나 초대로 참여해 첫 혼잣말을 남길 수 있다.
- 상대가 공개된 혼잣말에서 스레드 대화를 시작할 수 있다.
- 비공개 본문은 공개 시점 전 어떤 상대 API 응답, 알림, 접근성 라벨에도 포함되지 않는다.
- 한 사용자의 여러 1:1 공간 데이터와 알림이 서로 섞이지 않는다.
- 일반 상대는 초대 발급과 제거를 수행할 수 없다.
- 세 번째 가입은 서버에서 거부된다.
- 상대가 있는 만든 사람의 탈퇴 요청은 서버에서 거부된다.
- 새 상대는 참여 이전의 공개 기록과 잠긴 혼잣말 메타데이터를 볼 수 있다.
- 나가기·제거된 사용자는 기존 기록을 포함한 모든 공간 API, Realtime, 푸시 대상에서 제외된다.
- 나가기·제거 전에 공개된 작성 기록은 남은 활성 사용자에게 계속 표시된다.
- 멤버십 종료 후 작성자의 미공개 예약 혼잣말은 공개되지 않는다.
- lint, typecheck, unit test, RLS 통합 테스트, native build가 통과한다.

## Constraints
- React Native 0.85 + Expo SDK 56 Development Build + TypeScript
- Supabase Auth, Postgres, Realtime, RLS, Edge Functions 우선
- 모든 공간 데이터 접근은 현재 구현상 `group_id`와 활성 멤버십을 함께 검증한다.
- 서버 시간을 저장 기준으로 사용하고 사용자 시간대로 표시한다.
- 한국어 MVP로 핵심 루프를 검증한 뒤 일본어를 추가한다.
- 현재 구현은 `group_*` 명명을 임시 유지하되 `member_limit = 2`로 1:1 정책을 강제한다.

## Monetization Direction
- P0에는 구독 결제를 넣지 않는다.
- 감정 표현, 예약 공개, 공개 스레드는 무료 핵심 가치로 유지한다.
- 공개된 혼잣말 기록은 무료/유료와 무관하게 전체 열람을 유지한다.
- 무료 플랜은 사용자가 직접 만든 1:1 공간을 최대 3개까지 허용한다.
- 구독 플랜은 직접 만든 1:1 공간을 최대 10개까지 확장한다.
- 구독 취소 후 결제 기간이 끝나면 최근 생성 공간부터 무료 한도를 초과한 공간을 비활성화한다. 비활성 공간은 리스트에 표시하지만 진입, 작성, 기분 체크인, 스레드 접근은 막는다.
- 공간별 월간 리포트는 유료 플랜에서 열람한다. 무료 사용자는 리포트 도착 메타데이터와 구독 유도 CTA만 본다.
- 월간 리포트에는 감정 흐름, 공개된 혼잣말과 스레드 기반 히스토리 요약, 자주 등장한 키워드 상위 3개, 대화가 이어진 순간을 포함한다.
- 월간 리포트는 텍스트 요약만 제공하지 않고, 감정 흐름 그래프, 키워드 카드, 대화가 이어진 순간 타임라인처럼 작고 따뜻한 도식 요소를 함께 제공한다.
- 공개 전 리마인더, 공간별 알림 세분화, 북마크, 대화 회복 프롬프트, 기념일 리마인더는 추가 검토 전까지 보류한다.

## Open Questions
- 앱 이름과 번들 식별자
- 1:1 관계 유형을 연인 중심으로 좁힐지, 친한 친구/가족까지 열어둘지
- 공간을 만든 사람이 상대를 제거할 수 있는 권한을 P0에 유지할지

## Agent Plan
1. PM: 5인 그룹 피벗 superseded 기록과 1:1 정책 기준 갱신
2. Tech Architect: 기존 `group_*` 구현을 1:1 정책으로 제한한 상태의 리네이밍/마이그레이션 전략 검토
3. UX/UI: 사용자 노출 명칭을 1:1 공간 기준으로 정리
4. Backend/Frontend: 세 번째 참여 거부, 1:1 문구, 피드/상대 현황 검증
5. QA + Security + Accessibility
